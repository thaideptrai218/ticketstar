TicketStar

Full-stack ticketing marketplace platform with event creation, ticket sales, QR check-in, and role-based access control.

Explore Features

Core Features

🎯

Event Management

Organizers can create, update, and manage events with ticket tiers, pricing, and availability quotas.

🎫

Ticket Sales

Attendees can browse events, purchase tickets via SePay (VietQR), and receive QR tickets instantly.

📱

QR Check-in

Staff can scan attendee QR codes for instant event entry validation with real-time status updates.

🔐

Advanced Auth

JWT with refresh token rotation, TOTP MFA, Redis rate limiting, and token blacklisting.

💳

SePay Integration

Real VietQR payment integration with webhook processing and automatic order confirmation.

📊

Analytics Dashboard

Real-time sales statistics, check-in metrics, and revenue tracking for organizers.

Security Features

🔑

JWT httpOnly Cookies

5min access tokens with 7-day refresh tokens and automatic rotation.

📱

TOTP MFA

Two-factor authentication with recovery codes and AES-256 encryption.

🚦

Rate Limiting

Redis distributed sliding-window rate limiting per IP address.

🔒

Password Security

Argon2id hashing with OWASP-compliant parameters.
